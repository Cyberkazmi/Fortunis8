# Fortunis8 Web POC

This isolated React + FastAPI visual POC was transferred from the Manus Webdev project into the `manus-sync` branch for review. It is intentionally separate from the existing Telegram backend and is not a production integration.

Source Webdev checkpoint: `5369838309bf60e97de308c4d66190add5fe180e`.

The POC uses sample data and does not execute Supabase migrations, use production credentials, or claim real authentication, notifications, readings, rewards, or persistence.
